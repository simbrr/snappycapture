# SnappyCapture

A native macOS app for screenshots, screen recording and annotation, with a built-in video editor (Cutroom).
Everything runs on your Mac; nothing is uploaded unless you connect your own cloud bucket.

- **Website:** https://simbrr.github.io/snappycapture/
- **Download:** [SnappyCapture.dmg](https://github.com/simbrr/snappycapture/releases/latest/download/SnappyCapture.dmg) (macOS 15 or later, Apple Silicon; signed and notarized)
- **Problems or ideas:** [open an issue](https://github.com/simbrr/snappycapture/issues)

This repository holds the website and the releases. Download counts are recorded daily in
[`stats/downloads.csv`](stats/downloads.csv).
